# Opportunity Orbit

An independent, playful spin-the-wheel project powered by the [PerkCommons public dataset](https://github.com/PerkCommons/data). Spin once to choose a category, then spin again to reveal an opportunity from that category. Every opportunity you draw is removed from future spins **in this browser** until you reset your history.

**Live site:** https://codwastaken.github.io/opportunity-orbit/

## How it works

- Spin 1 uniformly chooses among categories that still have eligible, unspun opportunities.
- Spin 2 uniformly chooses among the currently eligible, unspun opportunities in that category.
- To keep the labels readable, the wheel visually displays up to eight sampled candidates **including the already-uniformly-drawn winner**. The shortlist is not the selection pool; every eligible entry still has the same chance of being chosen.
- The chosen opportunity is saved to first-party `localStorage` and permanently excluded from future spins **on that browser**, including across reloads. Browsers/devices do not share histories. Private browsing/storage clearing or **Reset history** allows repeats again.
- You may spin again in the same category or start with a fresh category spin. A depleted category disappears automatically from future spins.
- By default, only records not marked `unconfirmed` are in the draw. The opt-in toggle includes unconfirmed records with explicit warnings and provider links. General products, unrelated resources, and disputed/expired records remain excluded.

## Data and updates

**Source of truth:** [PerkCommons/data](https://github.com/PerkCommons/data), licensed CC0 1.0. This project neither changes the data repository nor modifies `perkcommons.com`.

The static catalog is generated by `scripts/build-catalog.mjs`, which reads the canonical JSON records, category taxonomy, and editorial scope decisions. It supports legacy v1 records and v2 records explicitly marked `defaultSearchEligible: true`. V2 items that have not been explicitly marked eligible are *not* included by inference.

GitHub Actions checks out `PerkCommons/data` independently, builds the site, and deploys to GitHub Pages on every push to `main`, nightly, and when manually dispatched. The generated catalog embeds the source commit SHA for traceability. There is **no runtime API key, database, third-party analytics or cookie banner**.

Publication and listed status do not guarantee current availability, provider approval, or individual eligibility. Always verify the official provider link; an unconfirmed record especially needs human source review. The wheel is not affiliated with or endorsed by the listed providers.

## Run locally

```bash
git clone https://github.com/CodWasTaken/opportunity-orbit.git
git clone https://github.com/PerkCommons/data.git
cd opportunity-orbit
npm ci
DATA_REPO_PATH=../data npm run catalog
npm run dev
```

Open the local URL shown by Vite. For production:

```bash
DATA_REPO_PATH=../data npm run build
npm test
npm run test:e2e
```

The game is TypeScript + vanilla browser APIs, bundled using Vite. Layout and wheel animation are CSS; reduced-motion preferences skip the animated spin. The outcome is chosen with browser cryptographic randomness before animation.

## Privacy

All no-repeat history, timestamps and settings remain in `localStorage` on the user's device, without any server-side tracking. No account, identity, user analytics, cookies or API submissions are required. Static page requests are served by GitHub Pages, subject to GitHub's normal infrastructure logs and privacy policies.
